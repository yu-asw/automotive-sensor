# 강사용 진행표 — ROS 2 데모 워크숍

## 180분 진행

| 시간 | 내용 | 진행 확인 |
|---|---|---|
| 0–15분 | 구성 설명, PC/D3 구분, SSH 접속 | 모든 학생이 D3 OS/CPU 확인 |
| 15–30분 | ① talker/listener | 연속 수신 확인 |
| 30–45분 | ② PC–D3, Domain ID | 원격 수신 및 불일치/복구 |
| 45–65분 | ③ 거북이 운전 | 토픽 명령과 위치 구분 |
| 65–85분 | ④ 서비스·파라미터·액션 | 생성·색 변경·회전·취소 |
| 85–95분 | 휴식 | |
| 95–130분 | ⑤ 카메라 | 직접 캡처 → 원격 영상 → 빈도 비교 |
| 130–160분 | ⑥ 기록·재생 | 거북이 필수, 카메라 선택 |
| 160–180분 | 자유 실험·결과 정리 | 개별 결과 기록 |

빌드와 이미지 플래시는 수업 전에 끝냅니다. SSH 접속 문제로 15분을 넘기면 해당 학생은 PC 데모로 진행하고 강사가 보드 문제를 별도로 확인합니다. 카메라가 실패하면 거북이 bag으로 기록·재생 목표를 달성합니다. 보드·카메라 항목은 미실시 또는 실패로 남깁니다.

## 사전 리허설 — 실제 결과를 입력할 것

현재 이 체크리스트는 미완료입니다. 로컬 문서 검사로 체크하지 않습니다.

- [ ] Ubuntu 22.04 데스크톱에서 Humble 및 PC 패키지 설치 확인
- [ ] D3 이미지 부팅과 SSH 서버 확인; 보드별 IP·계정·인증 방법·서버 지문 배부
- [ ] 학생은 PC 터미널에서 SSH 접속; D3 디스플레이/X11 없이 실행
- [ ] 팀별 Domain ID 배정 및 같은 보드를 공유할 때의 사용 순서 확정
- [ ] D3 자체 talker/listener 실제 수신
- [ ] PC–D3 실제 수신 및 Domain ID 복구
- [ ] PC에서 turtlesim·rqt_graph·서비스·파라미터·회전 액션·F 취소
- [ ] D3 카메라 장치·포맷·해상도 확인, V4L2 캡처
- [ ] PC 뷰어 실제 영상 및 양쪽 수신 빈도 측정
- [ ] 거북이 bag 기록·재생; 카메라 bag 5~10초 기록·재생
- [ ] 오프라인 ZIP 압축 해제 후 index.html 열기

여러 학생이 한 D3를 함께 쓰면 Domain ID만 다르게 해도 USB 카메라 장치는 공유됩니다. 카메라 노드는 한 명이 실행하고 같은 팀 Domain에서 함께 관찰하거나 순번을 정합니다. 장치를 여러 노드가 동시에 열지 않게 합니다.

학생 PC의 설치/화면/망이 준비되지 않으면 강사 데스크톱에서 시연할 수 있지만, 이를 학생 개별 실행 완료로 기록하지 않습니다.

## 설명 포인트

- SSH 연결과 DDS 통신은 서로 다른 경로다.
- 노드 실행 위치와 결과 표시 위치를 구분한다.
- 토픽은 데이터 스트림, 서비스는 요청/응답, 액션은 목표·피드백·결과와 취소다.
- 센서 드라이버와 뷰어를 바꿔도 메시지 인터페이스로 연결한다.
- bag은 실험 당시의 토픽 데이터를 보관한다. 원래 센서 없이 재현할 수 있지만 물리 세계 자체를 재현하는 것은 아니다.

## 자료 재생성

Python 3와 `Markdown` 패키지가 있는 별도 도구 환경에서 저장소 루트를 기준으로 실행합니다.

```bash
python3 workshops/ros2-demos/scripts/build-materials.py
```

생성물: 웹 실습서 `index.html`, 보조 웹 문서, `downloads/ros2-demos-workshop.zip`. 기존 ros2-camera ZIP은 별도 자료로 유지합니다.

## 작성 환경 검증 기록 — 2026-11-04

macOS에서 확인한 항목:

- 실습서의 Bash/sh 명령 블록 33개 구문 검사 통과
- 보조 셸 스크립트의 Bash/POSIX sh 구문 검사 통과
- 잘못된 Domain ID·역할 입력 거부, ROS 미설치 상태 실패 반환 확인
- HTML 4개 페이지의 로컬 링크·목차 앵커 검사 통과
- ZIP CRC 검사 및 압축 해제 파일과 원본의 일치 확인

이 환경에는 ROS 2가 없으며 D3 SSH 접속 정보도 이번 작업에서 제공되지 않았습니다. 따라서 실제 패키지 설치, DDS 송수신, GUI 표시, 카메라, bag 재생은 실행 검증하지 않았습니다. 위 사전 리허설에서 확인해야 합니다.
