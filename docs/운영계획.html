01

과목이 다루는 범위

자율주행과 ADAS는 사람의 눈을 대신하는 센서에서 출발합니다. 이 과목은 차량 환경인식 센서 6종의 동작 원리, 사양(스펙) 해석, 인터페이스와 데이터 취득 방법을 다룹니다.

카메라 초음파 레이더 라이다 GNSS IMU

경계는 분명합니다. 이 과목은 "센서가 어떤 물리 원리로 세상을 측정하고, 그 데이터가 어떤 형태로 소프트웨어에 도달하는가"까지입니다. 그 데이터를 처리하는 알고리즘은 후속 과목의 몫입니다.

내용담당 과목
센서 원리 · 사양 · 인터페이스 · 데이터 취득자동차센서 (이 과목, 3-2)
CNN/RNN 등 학습 알고리즘딥러닝 (3-2, 병행 권장)
2D 영상 · 3D 포인트클라우드 신호처리, 객체인식자동차비전 (4-1)
센서퓨전 심화, 항법 · 환경인식 · 제어자율주행 (4-2)

OUTCOME이수 후 할 수 있게 되는 것

  1. 6종 센서의 동작 원리를 물리 수준에서 설명하고, 데이터시트의 주요 사양(해상도 · FOV · 분해능 · 검출거리)을 해석한다.
  2. 임베디드 보드에서 GPIO · I2C · UART · MIPI-CSI/V4L2 · GStreamer로 센서를 직접 연결하고 데이터를 취득한다.
  3. 카메라 캘리브레이션을 수행하고 내부/외부 파라미터와 왜곡 모델을 설명한다.
  4. 실차 공개 데이터셋(KITTI, nuScenes)의 카메라 · 라이다 · 레이더 데이터를 읽고 시각화 · 기초 분석한다.
  5. 센서별 강점과 한계(조도 · 날씨 · 거리 · 해상도)를 비교하고 센서퓨전이 필요한 이유를 설명한다.
  6. 여러 센서를 하나의 실시간 시스템으로 통합하고, 그것이 움직이는 차량 위에서 동작하게 만든다. ← 2명 편성에서 추가된 목표
02

학기 프로젝트 — 센서 통합 자율주행 미니카

PLATFORM플랫폼

TOPST D3-G(텔레칩스 TCC8050, 국산 차량용 반도체) + PiRacer 섀시 기반의 1/10 스케일 자율주행 차량 1대를 두 사람이 공동으로 구축합니다. 소프트웨어는 Ubuntu 22.04 + ROS2 Humble. 센서마다 ROS2 노드를 만들고 토픽으로 데이터를 주고받는 구조로, 실제 자율주행 소프트웨어 스택과 같은 방식입니다.

이 플랫폼(D-Racer)은 2026 SEA:ME 해커톤(폭스바겐그룹코리아 후원, 국민대 주관)의 공식 플랫폼입니다. 학기 결과물을 그대로 대회 출전이나 캡스톤디자인으로 이어갈 수 있습니다.

진행 순서는 "차를 먼저 굴리고, 센서를 하나씩 얹는다"입니다. 기초 이론 2주 → 카메라로 차를 굴린다(3~6주) → 라이다를 얹는다(7~9주) → 레이더를 얹는다(10~12주) → 통합(13~15주). 센서를 하나 얹을 때마다 원리 → 연결 · 취득 → 차량 기능화 → 시연 · 기록 네 단계를 반복합니다.
